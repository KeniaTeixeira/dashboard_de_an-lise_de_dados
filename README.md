# 📊 Dashboard de Análise de Salários na Área de Dados

Este projeto foi desenvolvido como **projeto final da Imersão de Dados com Python**, com o objetivo de analisar e visualizar informações salariais da área de dados por meio de um **dashboard interativo**.

A aplicação permite explorar os dados de forma simples, visual e dinâmica, facilitando a interpretação de tendências relacionadas a cargos, níveis de senioridade, formatos de trabalho e distribuição de salários ao longo dos anos.

---

## 🛠️ Tecnologias utilizadas

* **Python**
* **Pandas** para manipulação e análise de dados
* **Plotly** para criação de gráficos interativos
* **Streamlit** para desenvolvimento do dashboard web

---

## ⚙️ Funcionalidades
* Filtros interativos por
* Exibição de métricas principais
* Visualizações gráficas
* Tabela com os dados filtrados para análise detalhada.
